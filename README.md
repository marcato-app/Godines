# Godinês Esfiharia — site de pedidos

Site estático (HTML + CSS + JS, sem build) com cardápio, carrinho e envio do pedido pelo WhatsApp.

## Arquivos
- `index.html` — página
- `styles.css` — visual nas cores da logo
- `app.js` — cardápio, carrinho e mensagem do WhatsApp
- `assets/logo.svg` — logo redesenhada em vetor (qualidade infinita)
- `assets/logo-1024.png` — logo em PNG para redes sociais / impressão

## Editar
- **Preços e sabores:** lista `MENU` no início de `app.js`.
- **Número do WhatsApp:** constante `WHATSAPP` em `app.js` (formato `55` + DDD + número).

## Publicar (grátis)
GitHub Pages: Settings → Pages → branch `main` / pasta raiz. Também funciona em Netlify ou Vercel arrastando a pasta.
